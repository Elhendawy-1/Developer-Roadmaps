Web Fundamentals

1–2 days

Understand how the web works before writing any code. This phase is short by design.

Core Knowledge Pillars

  • Internet vs Web — The internet is the infrastructure. The web is a service on top of it.
  • Client / Server — Browser sends request → server sends response.
  • DNS — Translates domain names into IP addresses.
  • HTTP/HTTPS — Protocols for transferring data. HTTPS is encrypted.
  • Browser DevTools — Your #1 debugging tool.
  • VS Code + Terminal basics — Your development environment.

Complete modern CSS, Box Model, Flexbox, CSS Grid, animations, variables, and responsive design.

▶ Watch CSS Course on YouTube →

Part 1 — HTML

Key Focus: Semantic HTML, Accessibility, Clean Structure

  • Document structure, elements, tags, attributes
  • Headings, paragraphs, text formatting, links, images, lists, tables
  • Forms, input types, buttons, audio, video, iframe
  • Semantic HTML: <header>, <footer>, <nav>, <main>, <section>, <article>
  • Accessibility: alt text, aria-* labels, form labels, heading hierarchy

Part 2 — CSS Fundamentals

Key Focus: Box Model, Specificity, Positioning

  • Selectors, specificity, cascade, inheritance
  • Colors, units (px, rem, em, vw, vh), typography
  • Box model (box-sizing: border-box), display, positioning
  • Pseudo-classes, pseudo-elements, CSS variables

Part 3 — Flexbox

Key Focus: Centering, Navigation Bars, Card Layouts

  • Main/Cross axis, flex-direction, justify-content, align-items
  • flex-wrap, gap, flex-grow/shrink/basis

Part 4 — CSS Grid

Key Focus: Page Layouts, Photo Galleries, Dashboards

  • grid-template-columns, repeat(), minmax(), auto-fit / auto-fill
  • grid-gap, grid-column/row, grid-template-areas

Part 5 — Responsive Design

Key Focus: Mobile-First Approach

  • Viewport meta tag, media queries (min-width, max-width)
  • Fluid typography with clamp()
  • Breakpoints (Mobile ≤ 480px, Tablet ≤ 768px, Desktop ≥ 1024px)

Part 6 — Modern CSS & Polish

Key Focus: Transitions, Animations, Shadow Layers

  • Transitions, transforms (scale, translate, rotate), keyframe animations
  • Gradients, glassmorphism (backdrop-filter), multi-layer shadows

Practical Projects to Build

  • Personal Portfolio / Link-in-Bio page
  • Product Landing Page (Mobile-first)
  • Modern Analytics Dashboard UI (Grid + Flexbox)

JavaScript

6–10 weeks

JavaScript 2021 Course — Elzero Web School

FREE 188 videos • ~33h Arabic ★ 5/5

From programming logic to DOM manipulation, OOP, BOM, and asynchronous requests.

▶ Watch JavaScript Course on YouTube →

Mastering ECMAScript 6 (ES6) — Elzero Web School

FREE 36 videos • ~7h Arabic ★ 5/5

Destructuring, Arrow functions, Spread/Rest, Map, Set, Symbols, Classes, and Modules.

▶ Watch ES6 Course on YouTube →

Part 1 — JavaScript Basics

Key Focus: Data Types, Operators, Control Flow

  • Variables (let, const — never var)
  • Data types: Primitive vs Reference
  • Conditionals (if/else, ternary, switch)
  • Loops (for, while, for...of, for...in)
  • Functions (declarations, expressions, arrow functions, default params)

Part 2 — Intermediate JavaScript

Key Focus: Array Methods, Objects, Scope

  • Array methods: map, filter, reduce, find, some, every, flat
  • Object manipulation: destructuring, spread, Object.keys/values/entries
  • Scope (global, block, function), hoisting, closures
  • ES6+ features: template literals, optional chaining (?.), nullish coalescing (??)

Part 3 — DOM & Browser APIs

Key Focus: Interactive Web Apps

  • DOM selection: querySelector, querySelectorAll
  • DOM manipulation: creating, appending, removing elements, class lists
  • Events: addEventListener, event object, event bubbling, event delegation
  • Browser Storage: localStorage, sessionStorage

Part 4 — Asynchronous JavaScript

Key Focus: Working with APIs & Data Fetching

  • Synchronous vs Asynchronous, Event Loop, Call Stack
  • Promises: states, chaining, .then() / .catch() / .finally()
  • async/await, error handling with try/catch
  • fetch() API: GET, POST requests, headers, handling JSON

Core JavaScript Projects

  • To-Do Application with localStorage persistence
  • Real-time Weather App fetching from live REST API
  • Interactive GitHub Profile Finder with repository stats
